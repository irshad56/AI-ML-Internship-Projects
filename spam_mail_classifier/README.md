# AI-ML Internship Projects

This repository contains three complete **Machine Learning projects** developed during an internship.  
Each project includes **full code, trained models, data visualizations, and a fully functional Streamlit web app** (local run available, deployment not yet done).

---

## 📌 Projects Included

### 3️⃣ Spam Mail Classification (Multinomial Naive Bayes)
- Classifies emails as **Spam** or **Not Spam**
- Uses **Multinomial Naive Bayes (MNB)** with **TF-IDF vectorization**
- Includes **Confusion Matrix, Accuracy Score, Classification Report**
- **Streamlit web app for real-time email text classification**
- Trained model saved as `.pkl`

📂 Folder: `spam_mail_classifier`  
To run app:
```bash
cd spam_mail_classifier
pip install -r requirements.txt
streamlit run app.py
```
